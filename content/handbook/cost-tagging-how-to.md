# Tagging costs to a Contract / Project (staff)

## Why tagging matters

Contract Profitability, Budget vs Actual for a project, and project views depend on each cost carrying a **Contract / Project**. Costs without one stay in company overhead.

There are two links to get right:

1. **Cost → Project** — each expense, bill or supplier contract is tagged to a project.
2. **Project → Client Contract** — each project is linked to the client's service contract (**Administration → Projects**, field **Client Contract**).

Both are needed for costs to appear against a contract in Contract Profitability.

## Expense Register — one entry

1. Open **Finance → Expense Register**.
2. Add or edit an expense.
3. In **Contract / Project**, pick the project, or choose **Company overhead (not tied to a contract)** for costs that genuinely belong to the whole company (office rent, for example).
4. Save.

Staff Salaries and Employer SSNIT are linked to projects through payroll (each employee's assigned project), not on the Expense Register.

## Expense Register — several entries at once

1. Open **Finance → Expense Register**.
2. Tick the **Select** box on each entry you want to change.
3. When the bar showing "N selected" appears, click **Assign Contract / Project**.
4. Choose the project (or company overhead) and confirm.

## Accounts Payable

1. Open **Finance → Accounts Payable**.
2. When adding or editing a bill, set **Contract / Project**.
3. Save. The matching expense entry for the bill picks up the same project automatically.

You can change only the Contract / Project on an existing bill at any time — this does not create a second expense.

## Supplier Contracts

1. Open **Finance → Supplier Contracts**.
2. Open or create the contract.
3. Set **Contract / Project** and save. The monthly bills the contract creates carry that project.

## Link projects to client contracts

1. Open **Administration → Projects**.
2. Edit the project.
3. Set **Client Contract** to the client's service contract. Use **None (internal / overhead)** only for internal projects such as your own office.
4. Save.

## Check what is untagged

Ask the assistant **"What costs are not tagged to a contract this month?"** It lists untagged Expense Register entries, Accounts Payable bills and Supplier Contracts for the month (each bill counted once), and projects that are not linked to a client contract. Contract Profitability also warns about expenses without a project.
